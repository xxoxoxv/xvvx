# مخطط لوحة المالك — Owner Dashboard (Web)

> **المجال:** interfaces/web
> **المرحلة:** P7 — الواجهات
> **الحالة:** مخطط واجهة (Web Spec)
> **تاريخ الإنشاء:** 2026-08-15
> **المواءمة:** عقد API في `interfaces/api/contract.md`

---

## 1. الهدف
تعريف لوحة ويب للمالك المطلق (owner) لمراقبة الدولة وإصدار الأوامر: رؤية المهام، الوكلاء، الخزانة، التدقيق، والذاكرة.

## 2. تخطيط اللوحة (Layout)
```
┌─────────────────────────────────────────────────────────┐
│  [شعار الدولة]  لوحة المالك              [تنبيهات] [خروج] │
├──────────┬──────────────────────────────────────────────┤
│ القائمة  │  مؤشرات حية (KPIs)                            │
│ الجانبية │  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐          │
│          │  │مهام │ │وكلاء│ │خزانة│ │تدقيق│          │
│ - نظرة    │  │نشطة │ │نشطون│ │رصيد│ │معلّم│          │
│ - مهام    │  └──────┘ └──────┘ └──────┘ └──────┘          │
│ - وكلاء   │                                              │
│ - خزانة   │  [قسم نشط: سجل المهام / الأحداث]               │
│ - تدقيق   │  ...                                          │
│ - ذاكرة   │                                              │
│ - عمليات  │  [نافذة الأوامر السريعة]                       │
└──────────┴──────────────────────────────────────────────┘
```

## 3. الأقسام (Sections)
| القسم | المحتوى | المصدر |
|---|---|---|
| نظرة عامة | KPIs حية | تجميع من كل المجالات |
| مهام | قائمة المهام وحالاتها | `GET /api/v1/tasks` |
| وكلاء | الوكلاء النشطون | `GET /api/v1/agents` |
| خزانة | الرصيد والمعاملات | treasury endpoints |
| تدقيق | التدقيقات المعلّمة | `GET /api/v1/audit/{taskId}` |
| ذاكرة | الذكريات حسب المجال | `GET /api/v1/memory` |
| عمليات | صحة الوكلاء والتقارير | ops endpoints |

## 4. ميزات
- **تحديث حي:** WebSocket لكل تغيير حالة (أحداث `event_store`).
- **نافذة أوامر:** إدخال أوامر CLI مباشرة من اللوحة.
- **تصفية حسب المستأجر:** محدد tenant في الأعلى.
- **صلاحيات:** المالك فقط يرى كل شيء؛ باقي الأدوار رؤية محدودة.
