# federal/ — الحكومة الفدرالية

## التعريف
تجمع السلطات المركزية التي تدير الولايات وتحافظ على التوازين. تضم أربعة فروع: التنفيذية، التشريعية، القضائية، والخزانة. الحكومة الفدرالية لا تتدخل في الشؤون الداخلية للولايات إلا عند خرق الدستور.

## النطاق
السلطة التنفيذية (Orchestrator + Supervisors)، التشريعية (Policy Council)، القضائية (Audit Court + Arbitration + Constitutional Court)، والخزانة (Budgets + Token Issuance + Resource Allocation).
