# منسّقات الأسطول (Fleet Coordinators)

الطبقة المسؤولة عن إدارة وتنسيق وتوزيع المهام على أسطول من آلاف الوكلاء
(هدف المرحلة الأولى: 2800+ وكيل بكامل قوتهم بلا أخطاء).

## المكوّنات

- `agent_fleet.py` — `FleetRegistry` (سجل مفهرس حسب التخصص/الولاية/الدور) +
  `FleetCoordinator` (الهرمية الفدرالية + استيعاب الوكلاء المستوردين + التفعيل المعتمد).
- `test_agent_fleet.py` — اختبارات: التسجيل، التوجيه، الضغط الخلفي، عزل الولايات،
  سعة 2800+، سلسلة التدقيق، استيعاب المستوردين.

## المبادئ

- الولاء المطلق للمالك: كل قرار تنسيق قابل للتدقيق.
- المراقبة قبل الثقة: لا وكيل يتلقى مهمة إنتاجية قبل الاعتماد.
- اللامركزية الفدرالية: توجيه هرمي (ملك ← مشرفون ← منسقو ولايات ← عمال).
- التوسع الآمن: sharding حسب التخصص + backpressure لمنع الإغراق.
- لا بيانات وهمية: كل توجيه مُسجَّل في سلسلة hash قابلة للتدقيق.

## الاستيعاب من المرحلة 1 (السحب)

`FleetCoordinator.ingest_imported(citizens)` يستوعب الوكلاء المستوردين من
`agents/registry/imported_citizens.yaml` كمرشحين (status=candidate) بلا صلاحيات
إنتاجية حتى اجتياز التدريب والموافقة.
