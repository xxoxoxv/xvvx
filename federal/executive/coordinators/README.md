# coordinators/ — منسقو الولايات

## التعريف
ينسقون بين الولايات عند الحاجة لمهام متعددة المجالات. ينشطون فقط عند المهام المشتركة ويعودون للوضع الخامل بعدها.

## النطاق
سياسات التنسيق، سجلات المهام المشتركة.
