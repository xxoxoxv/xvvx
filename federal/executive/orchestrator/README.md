# orchestrator/ — رئيس الوزراء

## التعريف
الـ Orchestrator هو أعلى سلطة تنفيذية. يستقبل الطلبات، يحللها، يخطط، ويوزع المهام على الولايات (Domain Supervisors). لا ينفذ مهام بنفسه — دوره القيادة والتنسيق فقط.

## النطاق
خدمة orchestrator-service (:8001)، Temporal workflows، Planning Agent، توزيع المهام.
