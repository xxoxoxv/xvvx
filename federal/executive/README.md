# federal/executive/ — السلطة التنفيذية

## التعريف
تدير العمليات اليومية للنظام. Orchestrator هو رئيس الوزراء الذي يستقبل الطلبات ويوزع المهام. Supervisors هم الوزراء الذين يديرون كل ولاية. Coordinators ينسقون بين الولايات عند الحاجة لمهام مشتركة.

## النطاق
خدمات التنسيق، إدارة الوكلاء، توزيع المهام، تنفيذ السياسات، والمراقبة التشغيلية.
