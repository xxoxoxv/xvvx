# docs/governance — حوكمة العمل

## التعريف
هذا المجلد يحتوي القواعد التي تحكم **طريقة العمل** في المستودع، لا محتوى العمل.
الدستور في `core/constitution/` يحكم الدولة؛ وهذا المجلد يحكم من يبني الدولة.
كل مبرمج أو وكيل يعمل في AMOS-Federation ملزم بما فيه قبل أن يكتب سطرًا واحدًا.

## النطاق
**يدخل:** مبدأ العمل، دورة المراحل، قواعد المنع، بوابات الإنفاذ.
**لا يدخل:** المواد الدستورية (في `core/constitution/`)، المراسيم (في `royal/decrees.md`)، خطط التنفيذ (في `docs/audit/`).
