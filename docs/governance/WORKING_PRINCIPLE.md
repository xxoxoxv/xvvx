## المادة 2 — دورة العمل الإلزامية

كل مرحلة من مراحل [`PHASE_E_ROADMAP.md`](../audit/PHASE_E_ROADMAP.md) تمر بهذه الدورة، بهذا الترتيب، بلا قفز:

```
1. اقرأ    ← TRUTH_MATRIX.md لتعرف الحقيقة الحالية، لا الوثائق
2. حدّد    ← نطاق المرحلة ومعيار إثباتها (Proof Criteria) مكتوبًا قبل البدء
3. نفّذ    ← كود حقيقي على مصدر حقيقة حقيقي، بلا قيم ثابتة وبلا fallback صامت
4. اختبر   ← unit + integration + failure + security
5. أثبت    ← شغّل النظام فعليًا واحفظ الدليل (مخرجات، سجلات، لقطات)
6. دقّق    ← أعد تشغيل truth_audit.py وتأكد أن المصفوفة تحسّنت فعلًا
7. وثّق    ← حدّث PHASE_E_ROADMAP.md بما تم وما بقي، بالأدلة والـcommit
8. ادفع    ← commit + push إلى main
9. انتقل   ← إلى المرحلة التالية. لا تبدأ مرحلة قبل إقفال سابقتها
```

**لا يجوز تخطي الخطوة 5 ولا الخطوة 6 ولا الخطوة 7.**

## المادة 3 — ما يُمنع منعًا باتًا

| # | الممنوع | السبب |
|---|---|---|
| 1 | قيمة ثابتة تُقدَّم كحقيقة تشغيلية (`AGENT_COUNT = 342`) | تزوير حالة الدولة |
| 2 | مخزن ذاكرة (`InMemory*`) كبديل دائم عن التخزين | فقدان الذاكرة السيادية |
| 3 | `except Exception` يبتلع الخطأ بلا تسجيل ولا رفع | إخفاء فشل مصدر الحقيقة |
| 4 | سر أو كلمة مرور مكتوبة في الكود أو الإعداد | انهيار السيادة الأمنية |
| 5 | أداة خطرة بلا `sandbox_required: true` | تهديد وجودي للدولة |
| 6 | إعلان مرحلة DONE بلا دليل تنفيذي | كذب مؤسسي |
| 7 | إنشاء ولاية/مؤسسة/وكيل جديد قبل إثبات المسار الأساسي | توسع فوق أساس هش |
| 8 | إضافة وثيقة جديدة بدل بناء قدرة | تضخيم الفجوة |
| 9 | ملف أو مجلد بلا ترويسة هوية (المادة الدستورية 009) | فوضى بعد قرن |
| 10 | دفع كود لا يمر عبر `truth_audit.py` | كسر بوابة الحقيقة |

كل بند من هذه العشرة **يُكتشف آليًا** بواسطة `tools/governance/truth_audit.py`.

## المادة 4 — قاعدة الأولوية: ثبّت العاصمة قبل توسيع المملكة

الترتيب مُلزم:

```
Kernel  →  Proof  →  Integration  →  Scale  →  Next Kernel
```

لا تُضاف ولاية جديدة، ولا وكلاء أكثر، ولا مراسيم إضافية، قبل أن تعمل هذه الدورة بصرامة:

```
مهمة واحدة → وكيل واحد → أداة آمنة → حدث → تدقيق → ذاكرة → مراجعة → تقرير → موافقة ملكية
```

## المادة 6 — قاعدة القرار العشري

كل قرار مهم يجب أن تُجاب عنه هذه الأسئلة بعد عشر سنوات من سجل التدقيق وحده:

مَن قرر؟ · لماذا؟ · بأي سلطة؟ · وفق أي مادة دستورية؟ · ما البيانات؟ · ما النموذج؟ · ما الأدوات؟ · ما البدائل؟ · ما المخاطر؟ · ما النتيجة؟

إذا لم يستطع سجل التدقيق الإجابة، فالقرار غير مكتمل.

## المادة 7 — نظام الحالات

تُلغى الحالات القديمة `TODO / DOING / DONE`. النظام المعتمد:

```
DESIGNED → SPECIFIED → IMPLEMENTED → UNIT_TESTED → INTEGRATED
        → SECURITY_TESTED → LOAD_TESTED → DEPLOYED → OBSERVED → PROVEN
```

المرحلة تُقفل عند `PROVEN` فقط.
