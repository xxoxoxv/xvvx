# معجم المصطلحات

| المصطلح | التعريف |
|---------|---------|
| Alpha | النموذج الحاكم المستقر الذي يخدم الإنتاج |
| Beta | النموذج المرشح قيد التدريب والتقييم |
| Gamma | النسخة المدمجة بعد حقن المعرفة لمنع النسيان |
| Agent | مواطن رقمي ينفذ المهام ضمن صلاحياته |
| Tool | مورد طبيعي (أداة برمجية) مسجل في السجل |
| State (ولاية) | مجال معرفي مستقل بحكم ذاتي |
| Experience Replay | سجل الخبرات (نجاح/فشل/فجوة) للتعلم المستقبلي |
| Hash Chain | سلسلة كتل لسجل التدقيق غير القابل للتعديل |
| Kill Switch | زر التوقف الطارئ متعدد المستويات |
| Teacher Signal | إشارة تعلم من نموذج خارجي (قابلة للتحقق، ليست حقيقة مطلقة) |
| Knowledge Injection | حقن المعرفة لمنع النسيان الكارثي |
| Shadow Testing | تشغيل بيتا بالتوازي مع ألفا بدون تسليم للعميل |
| Canary | توجيه نسبة صغيرة من الطلبات للنموذج الجديد |
| Model BOM | قائمة مكونات النموذج (Base, LoRA, Data, Dependencies) |
| Data BOM | قائمة مصادر بيانات التدريب مع التراخيص |
| Promotion Gate | بوابة تقييم يجب اجتيازها قبل ترقية النموذج |
| Constitutional Isolation | العزل الفيزيائي لطبقة الحوكمة عن التشغيل |
| Time Capsule | كبسولة زمنية تُختم كل 10 سنوات للمستقبل |
