# قرارات معمارية (ADRs)

## التعريف
فهرس قرارات العمارة (Architecture Decision Records): سجل كل قرار معماري مهم في
الدولة، بسببه وبدائله وحالته، حتى لا يُنسى **لماذا** بُني شيء على هذه الصورة.

## النطاق
القرارات المعمارية وحدها: اختيار تقنية، أو نمط، أو حدّ بين طبقات. لا يدخل هنا
قرار دستوري (موضعه `core/constitution/` ويلزمه مرسوم)، ولا خطة تنفيذ (موضعها
`docs/audit/PHASE_E_ROADMAP.md`).
