# docs/contracts/schemas

## التعريف
مخططات JSON Schema التي تُعرِّف شكل كيانات الدولة وأحداثها: الوكيل، والمؤسسة، والواجهة، والذاكرة، والحدث، والموافقة، وحلقة التنفيذ، والرصد. هي العقد الشكلي الذي تُقاس عليه أي حمولة قبل قبولها.

## النطاق
مخططات JSON Schema لكيانات الدولة وأحداثها — العقد الشكلي للبيانات. لا يشمل عقود الأحداث السلوكية ولا سجل المخططات التشغيلي.
