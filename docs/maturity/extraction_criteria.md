# معايير جاهزية الاستخراج — Extraction Readiness Criteria

> **المجال:** docs/maturity
> **المرحلة:** P9 — النضج والفصل المستقبلي
> **الحالة:** معيار (Criteria)
> **تاريخ الإنشاء:** 2026-08-15

---

## 1. الهدف
تعريف متى وكيف يُفصل أي جزء من الدولة إلى وحدة مستقلة (استخراج) دون تقسيم مبكر يضر التكامل.

## 2. المرشحون للاستخراج
| الوحدة | المجال الحالي | الوحدة المستقبلية |
|---|---|---|
| المحرك | runtime | `amos-runtime` |
| الواجهات | interfaces | `amos-interfaces` |
| الأدوات | tools | `amos-tools` |
| الوكلاء | agents | `amos-agents` |

## 3. معايير الجاهزية (5 شروط)
لكي يُستخرج جزء، يجب تحقق جميع الشروط:

1. **عقد مستقر** — مخطط JSON Schema ثابت (لا تغييرات مدمرة خلال دورة إصدار).
2. **استقلال البيانات** — جداوله لا تتشارك مع مجالات أخرى إلا عبر واجهات معرّفة.
3. **اختبارات كاملة** — تغطية اختبارات ≥ 80% مستقلة عن باقي الدولة.
4. **وثائق كاملة** — NUCLEUS.md + عقود + تدفقات + اختبارات دخان.
5. **لا اقتران خفي** — لا تبعيات دائرية مع مجالات أخرى.

## 4. مصفوفة الجاهزية الحالية
| الوحدة | عقد مستقر | استقلال بيانات | اختبارات | وثائق | لا اقتران | جاهز؟ |
|---|---|---|---|---|---|---|
| runtime | ✓ P2 | ✓ P4 | ✓ P3 | ✓ P5/P6 | ✓ | نضج منخفض |
| interfaces | ✓ P2 | ✓ P4 | جزئي | ✓ P7 | ✓ | نضج منخفض |

> حاليًا جميع الوحدات في "نضج منخفض" — الاستخراج الفعلي مؤجل حتى نضوج CI والاختبارات (انظر ci_maturity.md).

## 5. قاعدة عدم التقسيم المبكر
لا يُستخرج أي جزء حتى تتحقق الشروط الخمسة جميعها، ويُعتمد بمرسوم ملكي (royal/decrees). التقسيم المبكر يُفقد الدولة تكاملها قبل النضوج.
