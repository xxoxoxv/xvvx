# docs/ — التوثيق

## التعريف
كل قرار معماري، كل دليل تشغيل، كل مخطط. التوثيق ليس ترفًا بل ضرورة للبقاء. بدون توثيق، يفقد النظام ذاكرة كيفية عمله، ويموت عند رحيل المهندسين الأوائل.

## النطاق
قرارات معمارية (ADRs)، أدلة تشغيل (Runbooks)، المخططات، خطة التنفيذ، معجم المصطلحات.
