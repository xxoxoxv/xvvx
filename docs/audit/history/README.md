# أرشيف تقديرات الاكتمال القديمة

**تحذير:** الملفات في هذا المجلد تحتوي على تقديرات ذاتية قديمة لنسب الإنجاز (100%، 92%، 85%).

هذه التقديرات **غير معتمدة** لأنها:
1. تتعارض مع نتيجة التدقيق الآلي الرسمي (`tools/governance/truth_audit.py`) الذي يُظهر 0 من 12 إقليمًا بحالة PROVEN
2. تستند إلى معايير مختلفة („الملف موجود" = „تم") بدل معيار „DONE = Capability Proven"
3. لم تُحدّث بعد اكتشاف 121 مخالفة موثقة (60 IN_MEMORY_STORE، 43 SILENT_FALLBACK، 10 HARDCODED_TRUTH، 7 HARDCODED_SECRET، 1 SANDBOX_DISABLED)

**المرجع المعتمد الوحيد للحالي:** `docs/audit/TRUTH_MATRIX.md` (مُولَّد آليًا بالأمر: `python tools/governance/truth_audit.py`)
