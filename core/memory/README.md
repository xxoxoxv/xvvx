# memory/ — الذاكرة / الثقافة

## التعريف
الذاكرة الجماعية للنظام تنقسم إلى أربع طبقات: تشغيلية (قصيرة المدى)، معرفية (منظمة)، خبرات (نجاحات وإخفاقات)، تاريخية (سجل زمني). الذاكرة التشغيلية سريعة ومؤقتة، والمعرفية دائمة ومنظمة، والخبرات تُستخدم للتعلم، والتاريخ يُحفظ للأبد ولا يُحذف أبدًا.

## النطاق
ذاكرة تشغيلية (Redis)، معرفية (Qdrant)، خبرات (PostgreSQL + MinIO)، تاريخية (أرشيف دائم).
