# core/constitution/ledger — السجل الدستوري

## التعريف
السجل الرسمي لكل حكم أصدرته النواة الدستورية على طلب فعل — سماحًا كان أم منعًا.
كل قيد يحمل بصمة القيد الذي سبقه، فتتشكل سلسلة: حذف قيد، أو تعديل محتواه، أو
إعادة ترتيب القيود، كلها تكسر السلسلة وتُكتشف فورًا عبر `ledger-verify`.
هذا السجل هو التطبيق العملي لحقّي الشفافية المطلقة وقداسة الذاكرة في المادة الأولى.

## النطاق
**يدخل:** قيود `CONSTITUTIONAL_VERDICT` الملحقة آليًا من المحرك.

**لا يدخل:** التحرير اليدوي بأي حال. لا تفتح `constitutional_ledger.jsonl` في محرر.
لا يوجد — ولن يوجد — إجراء لحذف قيد منه.
