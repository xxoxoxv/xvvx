# constitution/ — الدستور

## التعريف
يحتوي على القوانين العليا التي لا يمكن لأي وكيل أو خدمة مخالفتها. الدستور يحدد هوية النظام، حقوق وواجبات الوكلاء، الفصل بين السلطات، آلية التعديل، خط الخلافة، وقواعد الأرشفة. كل مادة دستورية تُخزَّن في ملف منفصل مع بصمة SHA-256 وتوقيع زمني. تعديل الدستور يتطلب موافقة 75% من مجلس السياسات وموافقة بشرية موقعة رقميًا.

## النطاق
الديباجة، المواد الدستورية (001-009)، سجل التعديلات، واجتهادات المحكمة الدستورية. بدون دستور، النظام مجرد فوضى.
