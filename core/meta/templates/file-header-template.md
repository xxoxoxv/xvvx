# قالب ترويسة الملف

كل ملف يجب أن يبدأ بهذه الترويسة:

```markdown
# {اسم الملف}

## الهدف
{ماذا يفعل هذا الملف ولماذا يوجد}

## النطاق
{ما الذي يشمله وما لا يشمله}

## المالك
{الجهة المسؤولة عن الصيانة}

## تاريخ الإنشاء
{YYYY-MM-DD}

## تاريخ آخر تعديل
{YYYY-MM-DD}

## بصمة SHA-256
{تُحسب تلقائيًا}
```
