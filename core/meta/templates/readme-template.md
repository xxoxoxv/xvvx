# قالب README للمجلد

كل مجلد يجب أن يحتوي على README.md بالشكل:

```markdown
# {اسم المجلد}

## التعريف
{5-10 أسطر تشرح ما هو هذا المجلد}

## النطاق
{ما يدخل وما لا يدخل}

## المالك
{الجهة المسؤولة}

## تاريخ الإنشاء
{YYYY-MM-DD}

## تاريخ آخر تعديل
{YYYY-MM-DD}

## المحتويات الرئيسية
{قائمة الملفات والمجلدات الداخلية}
```
