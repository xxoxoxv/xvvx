# core/constitutional_engine — النواة الدستورية

## التعريف
المحرك الذي يحوّل دستور الدولة من نصوص تُقرأ إلى سلطة تُنفَّذ. يعرض عليه كل طرف
في الفدرالية — تنفيذية، تشريعية، قضائية، خزانة، تاج، وكيل، نظام — كل فعل قبل
تنفيذه، فيصدر حكمًا: `ALLOW` أو `DENY`، مُعلَّلًا برقم المادة والبند والسبب.
المحرك لا ينفّذ شيئًا ولا يعرف كيف يُنفَّذ الفعل — يأذن أو يمنع فقط. وكل حكم
يصدره، سماحًا كان أم منعًا، يُقيَّد في سلسلة تجزئة لا يمكن حذف قيد منها أو تعديله
أو إعادة ترتيبه دون أن ينكشف.

## النطاق
**يدخل:** قراءة المواد 001–009، ختمها بـ SHA-256، تقييم طلبات الأفعال، إصدار
الأحكام، تسجيلها، والتحقق من سلامة الدستور والسجل.

**لا يدخل:** تنفيذ الأفعال، إدارة الوكلاء، سياسات التشغيل (تلك للسلطة التشريعية)،
تعديل نص أي مادة (ذلك حصر بالمادة الخامسة عبر `amendments/`).

## المحتويات

## الاستعمال
```python
from core.constitutional_engine import ActionRequest, Branch, ConstitutionalEngine

engine = ConstitutionalEngine(enforce_seals=True)
verdict = engine.evaluate(ActionRequest(Branch.EXECUTIVE, "legislate", "policy/tools"))
print(verdict.explain())
# DENY — 1 مخالفة دستورية:
#   [CRITICAL] A003 (المادة الثالثة — الفصل بين السلطات) · البند: الفروع الأربعة — الحدود · القاعدة R-003-1
#       السبب: الفرع «executive» يمارس «legislate» وهو اختصاص حصري للفرع «legislative».
```

من سطر الأوامر:
```bash
python -m core.constitutional_engine.cli verify         # بوابة: الدستور غير مُعدَّل
python -m core.constitutional_engine.cli coverage       # بوابة: لا مادة بلا حراسة
python -m core.constitutional_engine.cli ledger-verify  # بوابة: السجل غير معبوث به
python -m core.constitutional_engine.cli evaluate --actor executive --action legislate
```

## المبادئ الملزمة لأي تعديل على هذا المجلد
1. **الافتراض الأصلي هو المنع.** قاعدة تنفجر أثناء التقييم = رفض الفعل، لا تجاوزه.
2. **لا قاعدة يتيمة.** كل قاعدة مربوطة بمادة موجودة، وإلا رفض المحرك الإقلاع.
3. **لا مادة بلا حراسة.** مادة سارية بلا قاعدة تنفيذية = دين دستوري يُسدَّد لا يُتجاهل.
4. **لا دالة حذف في السجل.** الذاكرة مقدسة (المادة الأولى · 3) — المنع بالتصميم لا بالسياسة.
5. **لا قاعدة تُوسّع الصلاحية.** القواعد تُضيّق فقط.
6. **لا قاعدة بلا اختبار** يُثبت أنها تمنع فعلًا حقيقيًا: `tests/constitutional/`.
