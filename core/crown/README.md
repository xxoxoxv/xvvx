# نطاق التاج — جذر الثقة والحماية (E2.2/E2.3)

## الهدف
حماية أصالة الملك وسلطة التاج وهويته التعمية ومرساة الثقة وقناة الأمر ودورة حياة
المفتاح والسجل التاريخي واستمرار الدولة — حمايةً منفَّذة بالكود لا موصوفة في وثيقة.
وهذا النطاق يقوم على قاعدة واحدة لا تُنقَض:

> **حماية الملك ليست سلطةً على الملك.**

فكل ما هنا يراقب ويكشف ويحتوي ويُبلِّغ ويُثبت. ولا شيء هنا يُجيز قرارًا ملكيًّا
صحيحًا، ولا ينقضه، ولا يُصدر بديلًا عنه، ولا يستنتج خلوّ العرش.

**والتصحيح الجوهري في هذا النطاق:** المفتاح العام **ليس سرًّا**، فلا يُحمى بوصفه
سرًّا. المحميّ هو **مرساة الثقة** التي تُحدِّد أي مفتاح عام هو مفتاح التاج الصحيح.

## النطاق
تنفيذ جذر ثقة التاج: الهويات، وسجل المفاتيح، والمرساة، وبيئة التوقيع، ومدقق
الأوامر، والسجل، والاستمرارية، والخلافة، والاسترداد، ومكتبة التهديدات، والحارس.

**لا يدخل:** دلالات السيادة في `core/sovereignty/` (E2.1 — لم تُمَسّ)، ولا الدستور،
ولا الفدرالية، ولا منطق الأعمال، ولا وصول الشبكة، ولا العتاد (يُوصَف مرجعيًّا ولا
يُحاكى).

## الهرم

```
👑 الملك (بشر) → هوية بشرية سيادية → مصادقة التاج → عتاد أمني
   → 🔐 مفتاح التاج → مرساة الثقة → أمر سيادي موقَّع
      ├── المسار السيادي (اختصاص حصري)
      └── المسار الفدرالي (ممرّ لا مانع)
   والحارس إلى الجانب: يراقب · يكشف · يحتوي · يُبلِّغ 👑
```

## التحقق

```bash
python -m core.crown.cli crown-check     # بوابة الحدود المطلقة — 9 فحوص، رمز خروج حقيقي
python -m core.crown.cli boundary        # حدّ البرمجية والبشر بالأرقام
python -m pytest tests/crown/ -q --cov=core.crown --cov-branch
```

## الحدود المُعلَنة

الصدق شرط الأمن، فهذه ليست ادّعاءات حماية:

- **العتاد** (`HSM`، عنصر آمن، مراسم معزولة) موصوف مرجعيًّا،
  `implemented_in_repository: false`، وطلبُ توقيعٍ منه يرفع خطأً بدل أن يوهم.
- **22 تهديدًا من 38** تحتاج بشرًا وإجراءات لا برمجية.
- **10 تهديدات مُنمذَجة بلا تنفيذ** و**5 خارج مقدرة البرمجية** — بأسمائها في
  `python -m core.crown.cli boundary`.
- **قصّ ذيل السجل** لا يُكشَف من داخل الملف وحده؛ يحتاج تثبيت `tip_hash` خارجيًّا.
- **لا ادّعاء «أمن مطلق»**، ولا حماية مزعومة من تقنية غير متحققة.
