# observability/ — المراقبة

## التعريف
عيون النظام وآذانه. المقاييس تقيس الأداء، والتتبع يتبع كل طلب، والسجلات تسجل كل شيء. بدون مراقبة، لا يمكن اكتشاف الأخطاء أو الهجمات. المراقبة تغذي الحوكمة والتطور بالبيانات.
