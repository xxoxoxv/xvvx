# governance/ — الحوكمة

## التعريف
طبقة التحكم في السلوك المؤسسي. السياسات تحدد ما هو مسموح، والموافقات تتطلب توقيعات بشرية للقرارات الحرجة، والتدقيقات تسجل كل شيء في سلسلة كتل غير قابلة للتعديل. الحوكمة هي الضمانة الوحيدة لبقاء النظام ملتزمًا بدستوره.

## النطاق
السياسات (OPA/Rego)، الموافقات الموقعة (Ed25519)، سجل التدقيق (Hash Chain).
