# states/ — الولايات الفدرالية

## التعريف
كل ولاية هي مجال معرفي مستقل. لكل ولاية حكومتها المحلية من الوكلاء والأدوات والمعرفة. الولايات تتمتع بحكم ذاتي كامل داخل حدود الدستور. يمكن إضافة ولاية جديدة عبر قانون فدرالي.

## النطاق
ولايات: المال، القانون، العلم، الصحة، الثقافة، البنية التحتية. كل ولاية لها نفس البنية الداخلية.
