# agents/ — السكان / المواطنون

## التعريف
كل وكيل هو مواطن رقمي له هوية فريدة، سجل حياة، قدرات، وصلاحيات. هنا يُدار سجل السكان (الوكلاء) وهوياتهم ودورة حياتهم. الولادة هي إنشاء وكيل جديد، والموت هو إيقافه نهائيًا، والتقاعد هو نقله للأرشيف. لا يُسمح لأي وكيل بالعمل بدون هوية مسجلة.

## النطاق
سجل السكان، ملفات الهوية، دورة الحياة (الولادة/الموت/التقاعد)، مصفوفة المهارات.
