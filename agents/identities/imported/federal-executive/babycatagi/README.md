# BabyCatAGI — مواطن مستورد (babycatagi)

## التعريف
`BabyCatAGI` مورد خارجي مستورد إلى الفدرالية كـ**موظف مرشَّح** لا كعضو عامل. سُجِّل
تحت المعرّف `imported-fedexecutive-babycatagi` من مصدره [https://replit.com/@YoheiNakajima/BabyCatAGI](https://replit.com/@YoheiNakajima/BabyCatAGI)، وصُنِّف أصلًا في
«وكلاء محادثة ومساعدين»، وأُسكِن في مجال `federal-executive`،
وتخصصه الدقيق **task-management**، وخُصِّص له المكان
`federal/executive` داخل بنية الدولة. لم يُنسخ كود مصدره
إلى المستودع — تُسجَّل هويته ومصدره فقط، منعًا لتضخّم المستودع ولالتباس
التراخيص. حالته الآن: استيراده **مسجَّل**،
ودمجه **غير مدموج**، وترخيصه
**بانتظار المراجعة**، وفحصه الأمني
**بانتظار المراجعة**. لا يُمنح أي صلاحية تشغيل
إنتاجية قبل اجتياز الترخيص والفحص الأمني وتصنيف القدرات وتدريب المدرسة
(≥85%) وموافقة الحوكمة — تطبيقًا لمبدأ «المراقبة قبل الثقة».

## النطاق
**يدخل:** تسجيل هوية هذا المورد ومصدره وتخصصه وحالة تقييمه، وأثر تقدّمه في مسار
دورة الحياة `imported → classified → sandbox_review → school_training →
evaluation → employed | archived`.

**لا يدخل:** كود المصدر (غير مُستنسخ)، ومنح الصلاحيات (للحوكمة)، وأي تنفيذ
إنتاجي قبل الاعتماد، وأي وصول إلى أسرار أو مفاتيح.
