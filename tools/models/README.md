## التعريف
النماذج هي العقول المدبرة. ألفا هو النموذج الحاكم المستقر، بيتا هو المرشح للتجربة، جاما هو المدمج بعد التقطير، والنماذج الخارجية هي المعلمون والمستشارون. لكل نموذج سجل إصدارات كامل. لا يُستبدل نموذج حاكم إلا بعد اجتياز كل بوابات الحوكمة.

## النطاق
