# أدوات السيادة — إثبات تشغيلي لا وثيقة

## الهدف
إثبات علوّ السلطة الملكية **بالتشغيل** لا بالوصف. تحتوي هذه الأدوات على براهين
حيّة تُنصِّب تاجًا حقيقيًّا، وتُوقِّع مراسيم بمفتاح Ed25519 حقيقي، وتُمرّرها على
البوابة السيادية نفسها التي تستخدمها الدولة، ثم تُعلن ما وقع فعلًا. وتفشل بكود
خروج غير صفري إن نُقض أي مسار.

## النطاق
إثبات ومُدقّقات فقط. لا منطق أعمال، ولا وصول شبكة، ولا كتابة في حالة الدولة.
