# tools/ — الموارد / الأدوات

## التعريف
الأدوات هي الموارد الطبيعية للنظام. لكل أداة ملف manifest يصف مدخلاتها ومخرجاتها ومستوى خطورتها وصلاحياتها. الأدوات لا تعمل إلا داخل صندوق رمل (Sandbox) حسب تصنيف الخطورة. بدون سجل أدوات صارم، يصبح النظام غير آمن.

## النطاق
سجل الأدوات، مخططات المدخلات/المخرجات، رخص الاستخدام، الاعتماديات.
