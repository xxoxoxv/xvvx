# المادة التاسعة — قانون هوية الملفات

## القاعدة الذهبية
لا يُسمح بإنشاء أي مجلد أو ملف بدون تعريف. التعريف هو الهوية، والهوية هي ما يمنع الفوضى بعد قرن.

## قواعد هوية المجلد
كل مجلد يجب أن يحتوي على `README.md` يشرح:
1. اسم المجلد
2. التعريف (5-10 أسطر)
3. النطاق (ما يدخل وما لا يدخل)
4. المالك (الجهة المسؤولة)
5. تاريخ الإنشاء
6. تاريخ آخر تعديل
7. قائمة المحتويات الرئيسية

## قواعد هوية الملف
كل ملف يجب أن يبدأ بترويسة تعريفية:
```
# اسم الملف
## الهدف: ...
## النطاق: ...
## المالك: ...
## تاريخ الإنشاء: ...
## تاريخ آخر تعديل: ...
## بصمة SHA-256: (تُحسب تلقائيًا)
```

## الإنفاذ
- CI/CD يفشل إذا وُجد مجلد بلا README أو ملف بلا ترويسة.
- سكربت `tools/governance/check_repository_identity.py` يفحص المستودع.
- لا merge يُقبل دون اجتياز فحص الهوية.

## الاستثناءات
- ملفات `.gitignore`، `.gitattributes`، وأمثلة صريحة (`.example`) معفاة.
- الملفات الثنائية (صور، أوزان نماذج) تُعرَّف في README المجلس.
