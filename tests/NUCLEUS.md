# Tests — النواة

## الهدف
الاختبارات: خفيفة وسريعة، للتأكد أن كل نواة تعمل. اختبار دخان لكل وحدة.

## الواجهة
- اختبارات دخان لكل مجلد
- اختبارات تكامل بين الوحدات
- نتائج الاختبار مرتبطة بحالة كل وحدة

## الحالة
stub — جديد، ينتظر التأسيس

## الخطوات التالية
- إنشاء اختبار دخان لكل مجلد
- ربط النتائج بحالة الوحدات
- تفعيل CI/CD pipeline
