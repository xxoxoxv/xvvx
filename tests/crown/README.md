# اختبارات التاج — جذر الثقة والحماية (E2.2/E2.3)

## الهدف
إثبات — تنفيذيًّا لا وصفيًّا — أن أصالة الملك وسلطة التاج وهويته التعمية ومرساة
الثقة وقناة الأمر ودورة حياة المفتاح والسجل التاريخي والحارس، كلها محميّة فعلًا.
وكل اختبار هنا إمّا **هجوم يجب أن يفشل**، أو **سلطة شرعية يجب أن تنفذ**. وما لا
يُختبَر لا يُدَّعى: التهديدات غير المنفَّذة تُسمّى بالاسم في مكتبة التهديدات ولا
تُعَدّ حمايةً.

## النطاق
`core/crown/` بمجملها: الهوية، وسجل المفاتيح، ومرساة الثقة، وبيئة التوقيع، ومدقق
الأوامر، والسجل، والاستمرارية، والخلافة، والاسترداد، ومكتبة التهديدات، والحارس
السيادي، وواجهة سطر الأوامر.

**لا يدخل:** نواة السيادة `core/sovereignty/` (لها `tests/sovereignty/`)، ولا
الدستور، ولا الفدرالية.

## منهج الاختبار

1. **تعميةٌ حقيقية.** مفاتيح Ed25519 تُولَّد لحظيًّا في الذاكرة، والتوقيع والتحقق
   يجريان فعلًا. لا `monkeypatch` على دالة تحقق، ولا توقيع مُحاكى، ولا قيمة نجاح
   ثابتة.
2. **لا مادة مفتاح في المستودع.** كل مفتاح خاص عابر في ذاكرة العملية ويموت بانتهاء
   الاختبار. ولا يوجد في هذا المجلد ملف مفتاح ولا نصّ مفتاح.
3. **الهجوم أولًا.** لكل ضمان اختبارٌ يحاول نقضه: توقيع مُلفَّق، وأمر مُحرَّف،
   وبيان مفاتيح مُعبَث به، ومرساة مُستبدَلة، وحارس يحاول ترقية سلطته.
4. **ادّعاء الحماية مربوط بمرجع.** كل تهديد في `core/crown/threats.py` يدّعي حمايةً
   يحمل `test_refs` إلى اختبارات قائمة بالاسم، و
   `test_every_test_reference_resolves_to_an_existing_test` يقرأ ملفات هذا المجلد
   بـ`ast` ويفشل عند أول مرجع معلَّق. فإعادة تسمية اختبار تُسقط البوابة بصوت عالٍ
   بدل أن تُخفي ادّعاءً بلا دليل.

## التشغيل

```bash
python -m pytest tests/crown/ -q
python -m pytest tests/crown/ -q --cov=core.crown --cov-branch --cov-report=term-missing
python -m core.crown.cli crown-check      # بوابة الحدود المطلقة (البند 52)
python -m core.crown.cli boundary         # ما لا تحميه البرمجية، بالأرقام
```

## ما لا تُثبته هذه الاختبارات

الاختبار يُثبت سلوك البرمجية، ولا يُثبت العتاد ولا البشر. فحماية المفتاح الخاص في
وحدة أمنية، وأصالة الشخص أمام الجهاز، والإكراه، والحال الطبية، وأمن المنشأة —
كلها خارج ما يمكن لملف اختبار أن يقطع فيه. وهي مُسمّاة في
[`docs/security/HUMAN_SOFTWARE_BOUNDARY.md`](../../docs/security/HUMAN_SOFTWARE_BOUNDARY.md)
وفي `python -m core.crown.cli boundary`.
