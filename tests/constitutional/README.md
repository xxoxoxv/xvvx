# tests/constitutional — اختبارات النواة الدستورية

## التعريف
حزمة الاختبارات التي تُثبت أن دستور الدولة يعمل فعليًا لا نظريًا: أن فعلًا مخالفًا
يُرفض آليًا، وأن الرفض مُعلَّل برقم المادة والبند، وأن كل حكم يُقيَّد في سلسلة تكشف
أي حذف أو تعديل أو إعادة ترتيب. هذه الحزمة هي دليل إقفال المرحلة E1 — بدونها
تبقى النواة الدستورية ادعاءً لا قدرة مُثبَتة.

## النطاق
**يدخل:** كل قاعدة من القواعد التسع عشرة (اختبار منع + اختبار سماح)، تحميل المواد،
كشف تعديل نص مادة، سلامة سلسلة السجل، ورموز خروج بوابات CI.

**لا يدخل:** اختبارات الأداء، واختبارات المجالات الأخرى.
